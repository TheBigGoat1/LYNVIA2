
App Logic – Document Generator (Individuals)

Flow
1. Client generates the document.
2. Client downloads the document. For each document, the client can choose:
   • Send document for Review: CHF 20.-
   • Download Word or PDF version: 2 documents free per month, each document after CHF 5.-

If client chooses to SEND DOCUMENT FOR REVIEW:
3. Admin Lynvia receives a notification.
4. Admin Lynvia reviews the document (Word version only, available for download).
   – During this stage, client must have access to the progress of his order.
5. Admin Lynvia uploads final document.
6. Client receives the notification.
7. Client goes to 'My Documents' and downloads the document.

If client chooses to DIRECTLY DOWNLOAD the document in PDF or Word:
• If within the free limit → client can directly download the document.
• All downloaded documents can be found in 'My Documents' for downloading at any given moment, during 30 days.
• If NOT within the free limit → client pays → client downloads → 30-day history in 'My Documents'.

App Logic – Tax Return

Flow
1. Client chooses Tax Return → client fills the requested information → client pays → client is redirected to Tax Return module.
   – Since the client has already bought a tax return, there will be the following of his order on this page.
   – On this page, the client can also buy another tax return by clicking a button that redirects to the page with all Tax Return services.

2. Admin Lynvia receives a notification that Client X bought a Tax Return service.
3. A task is created and can be accessed.
4. Admin Lynvia has a pre-made list of documents. Some of the documents are mandatory, some aren't.
5. Admin Lynvia selects the required documents for each client.
6. The list is sent → client receives a notification.
7. Client can access the requested documents in the Tax Return module → the list appears.
8. Each requested document creates a line with an upload button.
9. Client can choose a line for a grouped document upload (if he has all documents in one file only), but he must select that: "I certify that all the requested documents are in this file and that missing documents create delays".
10. When all documents are uploaded by client, Admin Lynvia receives a notification.
11. Admin Lynvia downloads the documents to make the task / return.
12. When ready, Admin Lynvia uploads the final documents.
13. Client receives a notification.
14. Client can access the documents any time in 'Tax Return' and 'My Documents' with no time limit (this is kept in app).
 
App Logic – Scenario Generator

Flow
1. Client chooses scenario → fills the data (data will be memorized through a button or automatically).

IF WITHIN the free limit of 2 scenarios per month:
2. The scenario is analysed.
3. Client can either:
   a. Download the PDF generated by the app, OR
   b. Send for Review by a Lynvia Expert.

If client SENDS FOR REVIEW:
4. Admin Lynvia receives a notification.
5. A task is created and Admin Lynvia can download the scenario with all the data input by the client in Word format (not only the result, but data + result).
6. Admin Lynvia reviews and uploads the final document.
7. Client receives notification.
8. Client can access and download the document for 30 days in 'My Documents'.
   (Analysed scenarios will be kept here for user intuitive usage — make sure the buttons that lead to last generated scenarios lead here.)

IF NOT within the free limit:
9. Client must be redirected to payment when clicking the button to create scenario.
10. Client makes payment → client is redirected to the Result.

IMPORTANT: When the limit of 2 scenarios per month is reached, the amount to pay must appear in the submitting button. Example:
   [ Submit and Pay CHF 5.- ]
